# AWS LLM Security Gateway & Prompt Injection Firewall

An AWS serverless architecture designed to act as a secure proxy between end-users and Large Language Models (LLMs). This project implements defenses against the OWASP Top 10 for LLMs, specifically targeting Prompt Injection and Data Leakage.
